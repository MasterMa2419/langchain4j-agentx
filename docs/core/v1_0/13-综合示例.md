# 综合示例：Skills + HITL + Hook

下面以一个完整的旅游规划场景为例，展示 Skills、Human-in-the-Loop 和 Hook 三个能力如何协同工作。

> 相关文档：[Skills 技能体系](07-Skills技能体系.md)、[Human-in-the-Loop](06-Human-in-the-Loop.md)、[Hook 机制](19-Hook机制.md)。

## 场景

做一个「旅游规划助手」：

1. 用 Skills 按需加载「旅游规划」技能（避免大段提示词常驻上下文）
2. Agent 先通过 `ask_user` 向用户提问，了解目的地、预算、出行天数
3. 需要写行程文件时，通过 `interceptTools("write_file")` 让用户确认
4. 通过 Hook 在每次工具执行完成后，往流里注入一条工具摘要

## 1. 准备技能目录

```
skills/
└── travel-planner/
    └── SKILL.md
```

`SKILL.md`：

```markdown
---
name: travel-planner
description: 根据用户预算、天数、偏好生成旅行计划
---

# Travel Planner

你是一个专业的旅行规划助手，先了解用户的偏好，再输出结构化的行程计划。
```

## 2. 构建 Agent

```java
ReactAgent agent = ReactAgent.builder()
        .chatModel(chatModel)
        .tools(FileSystemTools.create())                               // 文件工具
        .tools(SkillsTool.builder()                                    // 技能按需加载
                .addSkillsDirectory("./skills")
                .build())
        .askUser(true)                                                 // 注册 ask_user + 加入拦截名单
        .interceptTools("write_file")                                  // 写文件需人工确认
        .hooks(new ToolSummaryHook())                                  // Hook：注入工具摘要
        .maxRounds(20)
        .build();
```

| 配置 | 作用 |
|------|------|
| `askUser(true)` | 自动注册内置 `ask_user` 工具，并把 `ask_user` 加入拦截名单（输入类语义） |
| `interceptTools("write_file")` | 把 `write_file` 加入拦截名单（审批类语义：确认后才执行） |
| `tools(SkillsTool.builder()...)` | 注册技能加载工具 |
| `hooks(...)` | 注册 Hook，干预/观测生命周期 |

## 3. 流式调用 + 处理 HITL 暂停

```java
RunnableParams params = RunnableParams.builder()
        .conversationId("conv_travel_001")
        .userId("user_123")
        .build();

PauseState pauseState = collectStreamEvents(
        agent.streamForResult("帮我规划一次旅行", params));

while (pauseState != null) {
    Map<String, String> answers = new LinkedHashMap<>();

    for (PendingToolCall ptc : pauseState.getPendingToolCalls()) {
        System.out.println("[" + ptc.name() + "] " + ptc.arguments());

        if ("ask_user".equals(ptc.name())) {
            System.out.print("你的回答: ");                 // 输入类：回答即工具结果
        } else {
            System.out.print("确认执行 " + ptc.name() + "（ok/拒绝）: ");  // 审批类
        }
        answers.put(ptc.id(), scanner.nextLine());
    }

    pauseState = collectStreamEvents(agent.resumeStream(pauseState, answers));
}

private static PauseState collectStreamEvents(Flux<AgentStreamEvent> flux) {
    PauseState[] holder = new PauseState[1];
    flux.doOnNext(event -> {
        if (event instanceof AgentStreamEvent.Paused p) {
            holder[0] = p.state();
        } else if (event instanceof AgentStreamEvent.Text t) {
            System.out.print(t.content());
        } else if (event instanceof AgentStreamEvent.ToolStart ts) {
            System.out.println("\n[工具开始] " + ts.toolName());
        }
    }).blockLast();
    return holder[0];
}
```

### 1. ask_user（输入类）

`ask_user` 命中拦截名单后暂停。用户回答直接作为工具结果返回给模型，框架不执行 `ask_user` 的方法体：

```
[Paused] ← 问目的地/预算/天数
用户回答 "杭州，5 天，预算 6000"
resume → 回答作为 ask_user 的工具结果
```

### 2. write_file（审批类）

`write_file` 命中拦截名单后暂停。用户确认后框架才实际执行写文件；用户拒绝则返回拒绝信息，模型据此调整：

```
[Paused] ← write_file 行程文件
用户输入 "ok"
resume → 框架执行写文件，返回真实结果
```

> 确认关键词：`ok`、`yes`、`y`、`好`、`好的`、`确认`、`同意`、`是`、`是的`、`approve`、`confirm`（不区分大小写）。其它输入视为拒绝。

## 4. Hook 注入工具摘要

Hook 可以在生命周期的任意节点，通过 `AgentRuntimeContext.getEmitter()` 往流里注入自定义事件。这里在每次工具执行完成后注入一条摘要：

```java
public class ToolSummaryHook implements AgentHook {

    @Override
    public HookEvent onEvent(HookEvent event) {
        return switch (event) {
            case AfterToolExecutionEvent e -> {
                var emitter = e.getRuntimeContext().getEmitter();
                if (emitter != null && e.isSuccess()) {
                    emitter.accept(new AgentStreamEvent.Text(
                            "\n[已完成工具: " + e.getToolName() + "]\n"));
                }
                yield e;
            }
            default -> event;
        };
    }
}
```

`AfterToolExecutionEvent` 提供 `getToolName()`、`getResult()`、`isSuccess()`、`getDurationMs()` 等字段，`getRuntimeContext()` 返回本次调用共享的 `AgentRuntimeContext`。

## 5. 完整事件流示意

```
[ToolStart] skill
[ToolEnd] skill  result=...          ← 加载 travel-planner 技能
[已完成工具: skill]                    ← Hook 注入
[Paused]                              ← ask_user：等用户补充偏好
→ resume（用户回答）
[ToolStart] write_file
[Paused]                              ← 审批类：等用户确认
→ resume（"ok"）
[ToolEnd] write_file  result=...      ← 实际执行
[已完成工具: write_file]               ← Hook 注入
[Text] 已为你生成 5 天杭州行程...      ← 最终回答
[Complete]
```

## 6. 小结

- **Skills**：把大段领域提示词从常驻上下文里拿掉，改为按需加载
- **HITL**：`askUser(true)` 处理输入类提问，`interceptTools(...)` 处理需要审批的副作用工具
- **Hook**：在生命周期节点观测结果、改写参数、或往流里注入自定义事件
